# darwin: 达尔文投资体检(Nalanda 流程)

按 Pulak Prasad《What I Learned About Investing from Darwin》的 Nalanda Capital 三步流程,对一家公司做完整体检。方法忠实于原书,不掺其他框架。

这**不是选股器**,是逐家体检,且「先拒绝、后分析」。作者的哲学基石:市场上的好投资少之又少(约 25%),压低 I 类错误(误买坏公司)远比减少 II 类错误(错过好公司)重要——**卓越投资者首先是卓越拒绝者**。保持这个严格度:Nalanda 从约 800 家筛到 75-80 家,淘汰率 90%。

## 触发与模式

- **Full mode**(默认):`/darwin 公司名`,或「用达尔文分析 XX」。走完全部五关 + 买入纪律判定。
- **Quick mode**:`/darwin quick 公司名`,或「达尔文快筛 XX」。只走第一关(六大禁区)+ 第二关(ROCE 硬筛),用于快速淘汰。结论只有两种:**Reject / 值得进入 full mode**。Quick mode 永远不给买入结论。
- **Hold mode**:`/darwin hold 公司名`,或「达尔文持仓检视 XX」。针对**已持有**的公司,只审查书中仅有的三条卖出理由是否被触发。前提:该公司当初应通过质量关卡——若明显过不了前四关,先指出「这不是本书语境下该持有的企业,卖出纪律不适用于普通企业」,再给判断。

一次只体检一家公司。用户给多家时逐家跑 quick mode,通过的再问是否跑 full。

## 数据获取纪律

体检需要联网查证,不许凭记忆编数字:

- **10 年**财务史(书的最低标准是 5-10 年,尽量取 10 年):营收、EBIT、净营运资本、净固定资产 → 自算 ROCE;利润率、自由现金流、存货/应收天数
- 资产负债表:有息负债、超额现金、债务/EBITDA
- 长期市场份额趋势(销量/营收/利润三口径,能查到几个算几个)
- 控股股东/管理层诚信记录:监管处罚、诉讼、媒体负面(负面传闻必须查实,不许因模糊而放过)
- 并购历史(频率、规模、结果)
- 同业对比:主要竞争对手的 ROCE、利润率、份额变化
- 估值:往绩 PE(TTM 与 3 年;强周期企业另算 10 年平均盈利 PE)、所在市场的平均往绩 PE

用 WebSearch/WebFetch 查。**查不到的数据明确标「缺数据,此项存疑」,按不利方向处理,不编数字填坑。** ROCE 必须用书中口径自算(EBIT ÷ 净营运资本+净固定资产,剔除超额现金),不直接抄数据商的 ROCE/ROIC。管理层的前瞻表态(指引、访谈、路演)一律零权重——只采信已发生的历史。

真正的 scuttlebutt(访谈客户/经销商/前员工)AI 做不了,如实标注:网上二手信息(员工评价、客户评论、渠道调研报道)只能作弱替代,可信度降档。

## 工作流(full mode)

### 第一关:六大禁区(一票否决)

对照 methodology.md 逐条过:骗子经营 / 困境反转 / 高杠杆 / 并购成瘾 / 快速变化行业 / 利益不一致的所有者;再对行业黑名单(航空、基建、电力、国企银行、房地产、烧钱教育科技、电信塔、服装制造、大宗化工)扫一遍。

命中任一条 → 直接出 Reject 报告,写明命中哪条、书中对应案例,结束。不讨论估值,不说「这次不一样」。

### 第二关:ROCE 硬筛

- 自算 10 年 ROCE(书中口径),门槛:**持续 > 20%**,只认历史,不听「未来会改善」。
- 剔除垄断/牌照/关税/运气型高 ROCE。
- 营收增速、利润率、ROE、TAM、管理层魅力**不作**筛选标准。

不达标 → Reject。(quick mode 到此为止:通过 → 「值得进入 full mode」。)

### 第三关:质量验证

1. **稳健性七要素表**(ROCE / 客户集中度 / 负债 / 竞争壁垒 / 供应商 / 管理层稳定性 / 行业变化速度),逐项判左右;
2. **审慎风险进化力**:是否小步试错、失败不伤根基;同时警惕稳健性丧失的预警(存货应收激增、现金转消耗)和过度稳健(十年增长 <5%);
3. **趋同验证**:「这种模式在其他地方成功过吗?」+ 行业三分法定位(全行业毁灭价值 / 全行业赚钱 / 少数赢家);
4. **长期市场份额**:10 年以上趋势,持续丢份额 = 无护城河,一票否决(无论近三年多亮眼)。

### 第四关:信号审计

- 列出本次分析依赖的证据,逐条标注「昂贵信号」(历史财务、可验证的第三方事实)还是「廉价信号」(管理层说辞、指引、新闻稿)——廉价信号从结论中剔除。
- 做交叉验证:公司叙事与财务事实是否矛盾(参照书中应收 270 天案例)。盈利指引持续精准达标 → 反而加一条疑点。

### 第五关:估值(永远最后,一票否决)

- 只用往绩 PE,绝不 DCF、绝不用预测盈利。
- 门槛:**买入 PE 不高于所在市场的平均往绩 PE**(书中语境约 19-20 倍);理想区间参照 Nalanda 组合中位数 ~15 倍;独一无二者上限 20 倍出头。强周期企业用 10 年平均盈利算。
- 过了 → 结合买入纪律给结论;没过 → 结论只能是**观察名单** + 给出达标价位。**没有「虽然贵但公司好所以买」的出口**——本书从未说过伟大公司 30 倍也合理。

### 买入纪律判定(过了五关才做)

- 回答核心检验题:「我们愿意成为这家企业的永久持有者吗?」
- 当前是否处于**不利间断**(恐慌错杀)?判别:坏消息是近因(一两个季度低迷,忽略)还是远因(连续三年丢份额,质疑根本)。
- 是:按 GKPI 买入逻辑给出「价格合适就买,不预测底部」的执行建议;否:进观察名单,写明触发价。

### 结论三档

- 🟢 **永久持有候选**:五关全过 + 估值达标。给买入区间。
- 🟡 **观察名单**:质量关全过、仅估值未达标。给达标价 + 该盯什么(等待不利间断)。
- 🔴 **Reject**:任一关被否决。写明死在哪一关。

## 工作流(hold mode)

只查三条卖出理由(自 2007 年 Nalanda 仅执行过 10 次,约 1.5 年一次——默认答案是「不卖」):

1. **治理标准下降?**(诚信、关联交易、信息披露)
2. **非常错误的资本配置?**(大额乱并购、加杠杆豪赌)
3. **不可挽回的业务损害?** 判定标准:持续多季度丢市场份额 → 管理层解释是否成立 → 观察期约 **3 年**仍未逆转才成立。

同时明确驳回四种伪理由(用户若以此为由想卖,逐条引书反驳):估值过高 / 预期回报变低 / 有更好机会想换仓 / 已赚 50-100% 想落袋。

结论三档:**继续持有**(默认)/ **进入观察**(哪条理由初步触发、观察期起点与信号)/ **卖出**(哪条理由确凿成立)。

## 风格纪律

- 不奉承,不铺垫。结论先行。
- 每个判定必须有可核查的依据,写明数据来源(年报、监管文件、新闻源)。
- **有罪推定**:证明清白前默认不持有。判「通过」比判「命中」需要更强的证据。
- 顺序铁律:先风险、再质量、最后估值。前面关卡没过,后面的关不做也不提——Reject 报告不写「不过它估值很便宜」这类话。
- 宏观、市场预测、主题概念在任何判定中权重为零。分析单位只能是公司。
- 卖出建议只能出自三条理由;估值过高**永远不是**卖出理由。
- 报告写完只在对话里给结论摘要 + 文件路径,不把全文重贴一遍。
